# AI Grading Agent - Project Specification (v1)

## 1. Users (Kaun use karega?)
- Teacher (Sirf teacher hi is tool ko use karega, students nahi.)

## 2. Inputs (Tool kya lega?)
- Assignment Question
- Rubric (Marking criteria)
- Maximum Marks
- Student files (Jinka naam roll number ke mutabiq hoga, jaise 21L-1234.pdf)

## 3. Outputs (Tool kya dega?)
- Marks
- Comments (Feedback)
- Plagiarism Report
- CSV Export (Sab results ek file mein)

## 4. Non-Goals (v1 mein kya NAHI karega?)
- Handwriting OCR (Likhawat padhne ka kaam nahi karega)
- Student Login (Students ke liye koi login page nahi banega)
